# Job Form User Guide

Welcome to the improved WiseStyle job creation form! This guide explains how to use the new features for faster, more efficient data entry.

## Overview

The job form has been enhanced with:
- **Searchable dropdowns** for customers, tailors, and styles
- **Visual calendar picker** for dates
- **Smart progress slider** that only appears when editing existing jobs

## Creating a New Job

### Step 1: Select a Customer

The customer dropdown now includes a **search feature** to help you find customers quickly.

**How to use**:
1. Click the customer field
2. A dropdown appears with a search box
3. Type any part of the customer's name (e.g., "ada" to find "Adaeze Okonkwo")
4. Use your mouse or arrow keys to navigate options
5. Press Enter or click to select

**Tips**:
- You can search by first name, last name, or full name
- Search is case-insensitive
- The search happens instantly as you type
- If you don't find anyone, check the spelling or add the customer first

### Step 2: Choose a Style

The style dropdown works the same way as the customer dropdown.

**Available styles**:
- Casual
- Formal
- Wedding Dress
- Evening Gown
- Suit (2-piece)
- Suit (3-piece)
- Traditional (Iro & Buba)
- Traditional (Kaftan)
- Traditional (Agbada)

**Quick tip**: Type the first few letters to filter options instantly.

### Step 3: Enter Measurements

Fill in the required measurements for the selected style. Different styles require different measurements.

### Step 4: Add Materials

Check the materials needed and select the appropriate options for each.

### Step 5: Pick Dates with the Visual Calendar

The **calendar picker** makes date selection easier and more visual.

**How to use**:
1. Click the date field (Order Date or Due Date)
2. A calendar popup appears
3. Use the **← →** arrow buttons to navigate months
4. Click any date to select it
5. Click **Today** button to quickly jump to today's date
6. Click the **X** button to clear a selected date

**Calendar features**:
- **Gold ring** = Today's date
- **Purple background** = Selected date
- **Gray text** = Days from previous/next month (clickable)
- **Bold text** = Today (if not selected)

**Keyboard shortcuts**:
- `Escape` - Close calendar without changing date
- Click outside - Close calendar

**Mobile friendly**: The calendar has large touch targets that work great on phones and tablets.

### Step 6: Assign a Tailor (Optional)

Use the searchable tailor dropdown to assign the job to a specific tailor. This field is optional when creating jobs.

**How to use**:
- Same as customer dropdown with search functionality
- Leave blank if you'll assign the tailor later
- Only active tailors appear in the list

### Step 7: Add Notes and Submit

Add any special instructions in the notes field, then click **Save Job** to create the job.

## Editing an Existing Job

When you open an existing job for editing, you'll see all the same fields **plus** the progress slider.

### Updating Progress

The **work-in-progress slider** appears only for existing jobs (not new ones).

**How to use**:
1. Drag the slider left or right to adjust progress
2. The percentage updates in real-time
3. The colored bar below shows visual progress
4. Click "Update Job" to save changes

**Progress indicators**:
- **0%** - Not started (red)
- **1-99%** - In progress (yellow/gold gradient)
- **100%** - Completed (green)

**Why it doesn't appear for new jobs**: A job that doesn't exist yet hasn't made any progress, so the slider would always be 0%. It only appears once the job is saved.

## Filtering Jobs

The jobs table also uses searchable dropdowns for filtering.

**Available filters**:
- **Style** - Filter by clothing type
- **Month** - Filter by due date month
- **Status** - Filter by job status (Pending, In Progress, Completed)

**How to use**:
1. Click any filter dropdown
2. Search or scroll to find your option
3. Select "All" to clear that filter
4. Multiple filters work together (e.g., "All Wedding Dresses due in March")

## Tips for Efficient Data Entry

### Keyboard Navigation

All dropdown fields support keyboard navigation:
- **Tab** - Move to next field
- **Space** or **Enter** - Open dropdown
- **↓ ↑** - Navigate options
- **Enter** - Select highlighted option
- **Escape** - Close without selecting
- **Home** - Jump to first option
- **End** - Jump to last option

### Search Tips

- **Be flexible**: You don't need to type the full name - "chi" finds "Chioma"
- **Start typing immediately**: The search box is automatically focused when you open a dropdown
- **Clear search**: Click the X button in the search box to reset
- **No results?**: Double-check spelling or try searching for a different part of the name

### Calendar Tips

- **Fast month navigation**: Click the arrow buttons multiple times to jump several months
- **Today shortcut**: Always click the "Today" button to quickly jump back to the current month
- **Change your mind?**: The X button clears the date, or you can click outside to cancel

### Mobile Usage

Both components work great on mobile devices:
- **Large touch targets** - Easy to tap on phone screens
- **Scrollable dropdowns** - Swipe through long option lists
- **Responsive calendar** - Calendar grid adapts to screen size
- **No typing required** - You can select everything by tapping

## Accessibility Features

The improved form is fully accessible for users with assistive technologies:

- **Screen reader support** - All components announce their state and options
- **Keyboard-only navigation** - Every feature works without a mouse
- **Focus indicators** - Clear visual feedback shows which element is active
- **ARIA labels** - Proper semantic markup for assistive devices

## Troubleshooting

### "I can't find a customer in the dropdown"

- Check if the customer exists in the system first
- Try searching by first name, last name, or phone number
- Make sure there are no typos in your search
- The customer might be archived - check with an admin

### "The calendar won't open"

- Make sure the date field isn't disabled
- Try clicking directly on the calendar icon
- Refresh the page if it's not responding

### "My selected date looks wrong"

- The calendar always uses your computer's local date/time
- Check your system date settings if dates seem off
- The format is Month Day, Year (e.g., "Jan 15, 2026")

### "The dropdown closed before I could select"

- Make sure you're clicking inside the dropdown area
- Don't click outside the dropdown boundaries
- Use keyboard navigation (Enter key) for more control
